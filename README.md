# SGRD — Defesa Civil de Goiana

React, TypeScript e Vite. Mapa de famílias, agrupamentos, calor e consulta de integrantes, integrado ao cadastro da equipe.

`npm ci` · `npm run dev` · `npm test` · `npm run typecheck` · `npm run build`

Rotas: `/` (mapa) e `/cadastro-equipe` (ficha da equipe). A navegação preserva a sessão e os rascunhos em memória.

A demonstração usa 500 famílias fictícias. Atualizar a página apaga os novos cadastros de teste. Dados permanentes dependem da API da equipe.

[Contrato de integração e fontes](docs/INTEGRACAO.md).
